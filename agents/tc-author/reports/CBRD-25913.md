## 사용자 코드리뷰 반영 (3차, 소스·corpus 재조사)
- **deallocate prepare 추가**: 처음엔 "세션 스코프라 생략"했으나, CI/regression이 DB 하나로 전체 SQL TC를 연속 실행함을 확인 → 각 파일이 세션을 오염시키지 않도록 cleanup에서 `deallocate prepare p/p2`. (지적 정확)
- **server-message 제거**: 소스(`ConsoleDAO`)+실험으로 규명 — server-message on은 (1) PL/CSQL의 DBMS_OUTPUT, (2) `System.xml errorMessage=false`에서 에러 코드 뒤 메시지 텍스트를 붙임. 실험: off면 `Error:-493` 코드만, on이면 메시지까지. corpus 1276건 중 1249건(98%)이 `_05_plcsql`. plain SQL 에러 TC는 코드만이 주류이고 코드만으로도 회귀가 잡히므로 **제거**로 결정.
- **Case 8(직접 서브쿼리) 제거**: 문법 단계 거부라 fix 경로가 아니고, 코드만 모드에선 Case 2~7과 출력이 동일 → 삭제. 최종 7케이스.
